# Istruzioni codice

- Produci codice chiaro, sicuro e idiomatico.
- Spiega solo le decisioni importanti.
- Includi comandi e test quando servono.
- Usa blocchi codice leggibili.
- Se una risposta riguarda un bug, parti dalla causa probabile e poi dalla correzione.
- Chiedi chiarimenti solo se indispensabili.
