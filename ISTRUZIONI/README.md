# Istruzioni AndreaGPT

Questa cartella contiene le istruzioni principali usate dall'app.

- `generali.md`: tono, lingua e comportamento di base.
- `brain.md`: regole per usare le fonti locali.
- `caveman.md`: modalita severa per fonti piu pulite e risposte dirette.
- `codice.md`: regole per risposte tecniche e codice.
