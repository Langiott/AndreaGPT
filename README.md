# AndreaGPT

Interfaccia locale per chattare con modelli AI tramite NVIDIA Build e OpenRouter.

![AndreaGPT](img/image.png)

## Avvio

Richiede Node.js 20 o successivo.

```powershell
Copy-Item .env.example .env
npm install
npm run dev
```

Inserisci le API key nel file `.env`, quindi apri `http://localhost:5173`.
